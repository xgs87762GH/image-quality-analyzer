## 核心功能

### 1. 图像质量分析

系统可以对图像进行全面的质量评估，包括：

- **模糊度检测**: 使用Laplacian方差算法检测图像清晰度
- **亮度分析**: 计算平均亮度，检测过曝或欠曝
- **信息熵**: 评估图像的信息量和复杂度
- **BRISQUE评分**: 无参考图像质量评估（可选）
- **审美评分**: 基于CLIP模型或AI模型的审美评估（可选）

### 2. 数据库存储

- **SQLite数据库**: 所有分析结果持久化存储
- **自动去重**: 基于文件哈希自动识别重复图像
- **快速查询**: 支持按评级、标签、质量分数查询
- **统计分析**: 自动生成质量统计报告

### 3. XMP元数据支持

- **写入元数据**: 将分析结果写入图像文件的XMP元数据
- **兼容性**: 兼容主流图像管理软件（Lightroom, Bridge等）
- **元数据字段**:
  - Rating: 1-5星评级
  - Label: 质量标签（High/Medium/Low/Very Low）
  - Subject: 关键词列表
  - Description: 详细指标JSON

## 质量评估

### 评估指标

1. **模糊度 (Blur Score)**
   - 算法: Laplacian方差
   - 范围: 0-∞（越高越清晰）
   - 阈值: < 100 视为模糊

2. **亮度 (Brightness)**
   - 算法: 平均像素强度
   - 范围: 0-255
   - 理想值: 150左右

3. **信息熵 (Entropy)**
   - 算法: 信息熵计算
   - 范围: 0-8
   - 阈值: < 5 视为信息量不足

4. **BRISQUE (可选)**
   - 算法: 无参考图像质量评估
   - 范围: 0-100（越低越好）
   - 需要: OpenCV quality模块

5. **审美评分 (可选)**
   - 方式1: CLIP模型（本地）
   - 方式2: AI模型（GPT-4V, Claude, Gemini, Ollama）
   - 范围: 0-10分

### 综合评分

系统将各项指标归一化后，按权重计算综合质量分数：

```
质量分数 = 模糊度×权重 + 亮度×权重 + 熵×权重 + 审美×权重
```

### 评级和标签

- **1-5星评级**: 根据质量分数自动映射
- **质量标签**: High / Medium / Low / Very Low
- **问题检测**: 自动识别模糊、亮度问题、低熵、高失真等问题

## AI分析

### 支持的AI模型

1. **GPT-4 Vision** (OpenAI)
   - 需要: OpenAI API密钥
   - 特点: 强大的图像理解能力

2. **Claude 3** (Anthropic)
   - 需要: Anthropic API密钥
   - 特点: 优秀的图像分析能力

3. **Gemini Pro Vision** (Google)
   - 需要: Google API密钥
   - 特点: 多模态理解能力

4. **Ollama** (本地)
   - 需要: 本地Ollama服务
   - 推荐模型: llava, qwen2-vl, qwen3-vl
   - 特点: 完全本地化，无需API密钥

### AI分析功能

- **图像描述**: 自动生成图像内容描述
- **质量评估**: AI评估图像质量
- **自定义评估**: 支持自定义评估问题和答案格式
- **审美评分**: 使用AI模型进行审美评估

### 自定义评估问题

支持设置自定义评估问题，例如：
- "是否为手机截图"
- "是否包含人物"
- "拍摄场景类型"

答案格式支持：
- 是/否
- 真/假
- 高/中/低
- 好/坏
- 有/无
- 文本描述

## 元数据管理

### XMP元数据写入

系统可以将分析结果写入图像文件的XMP元数据：

- **Rating**: 1-5星评级
- **Label**: 质量标签
- **Subject**: 关键词列表（质量标签、问题类型等）
- **Description**: 详细指标JSON

### 元数据读取

支持从XMP元数据读取：
- 已分析的图像可以直接读取结果
- 兼容其他软件写入的元数据

## Web界面

### 主要功能

1. **图像列表**
   - 查看所有已分析的图像
   - 搜索和筛选功能
   - 分页浏览
   - 缩略图预览

2. **图像详情**
   - 查看完整分析结果
   - 质量指标可视化
   - AI分析结果展示
   - 自定义评估结果

3. **统计分析**
   - 整体质量统计
   - 标签分布
   - 评级分布
   - 质量分数分布

4. **重复检测**
   - 基于文件哈希查找重复图像
   - 显示重复图像组

5. **回收站**
   - 查看已删除的图像
   - 恢复或永久删除

### 设置功能

- **基础设置**: 自动分析、审美评估方式、每页显示数量
- **分析设置**: 并发分析数量
- **AI模型设置**: 选择AI模型、配置API密钥
- **自定义评估**: 设置评估问题和答案格式
- **图片源目录**: 管理图片源目录列表

## 回收站功能

### 功能特性

1. **软删除**
   - 删除的图像移动到回收站（不真正删除文件）
   - 保留原目录结构
   - 记录删除时间

2. **恢复功能**
   - 从回收站恢复图像
   - 自动移回原位置
   - 处理路径冲突

3. **永久删除**
   - 真正删除图像文件
   - 删除数据库记录
   - 删除缩略图

### 使用场景

- 误删恢复
- 批量清理
- 临时删除（后续决定是否永久删除）

## 批量处理

### 支持的操作

- **批量分析**: 同时分析多张图片
- **批量导入**: 从多个目录导入图片
- **批量删除**: 批量删除图片
- **批量恢复**: 批量恢复图片

### 性能优化

- **并发处理**: 可配置并发数量（默认3张）
- **进度显示**: 实时显示分析进度
- **错误处理**: 单个失败不影响整体

## 自动导入

### 功能说明

- **自动检测**: 启动时自动从配置的目录导入图片
- **目录验证**: 自动验证目录是否存在
- **脏数据清理**: 自动清理源文件不存在的记录
- **静默模式**: 支持静默导入（不输出详细信息）
