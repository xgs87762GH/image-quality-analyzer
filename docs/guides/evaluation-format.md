## 核心定义 (Schema)

### 评估问题结构

评估问题使用数组格式，每个问题包含以下字段：

```json
[
  {
    "issue": "问题描述文本",
    "return_type": "array",
    "options": ["选项A", "选项B"]
  },
  {
    "issue": "数值评分问题",
    "return_type": "float",
    "min": 0,
    "max": 10
  },
  {
    "issue": "文本描述问题",
    "return_type": "text"
  }
]
```

### 字段速查表

| 字段                  | 类型     | 必填 | 说明                                                             |
| --------------------- | -------- | ---- | ---------------------------------------------------------------- |
| **issue**       | string   | 是   | 提问给 AI 的具体内容，建议描述精确，避免歧义                     |
| **return_type** | string   | 是   | `array` (枚举选择), `float` (数值评分), `text` (自由文本)  |
| **options**     | string[] | 否   | 当 `return_type` 为 `array` 时必填，定义可选选项数组         |
| **min**         | number   | 否   | 当 `return_type` 为 `float` 时推荐填写，定义最小值（默认 0） |
| **max**         | number   | 否   | 当 `return_type` 为 `float` 时推荐填写，定义最大值（默认 1） |

### 字段说明

- **issue** (string, 必需): 评估问题文本，建议使用自然语言，描述清晰明确。这是AI会看到的问题描述
- **return_type** (string, 必需): 返回类型，支持：
  - `array`: 数组类型，从预定义选项中选择，AI必须从 `options` 中选择一个值返回
  - `float`: 浮点数类型，范围由 min/max 定义，AI返回一个数值（字符串格式）
  - `text`: 文本类型，自由文本描述，AI可以返回任意文本
- **options** (string[], 可选): 仅当 `return_type` 为 `array` 时**必填**，定义可选选项数组，如 `["是", "否"]`, `["高", "中", "低"]`
- **min** (number, 可选): 仅当 `return_type` 为 `float` 时使用，定义最小值（默认 0）
- **max** (number, 可选): 仅当 `return_type` 为 `float` 时使用，定义最大值（默认 1）

### 注意事项

- **CLIP模式限制**: 当审美评估方式选择为"CLIP"时，评估设置页面不会显示，因为CLIP模式不支持自定义评估问题
- **批量导入是追加**: 批量导入的问题会追加到现有列表末尾，不会替换已有问题
- **自动保存**: 所有评估问题配置会自动保存到浏览器本地存储，无需手动保存

## 生产级评估案例库

以下案例可直接复制到批量导入功能中使用，已针对实际工程场景优化。

### 场景一：硬性质量清洗 (垃圾图过滤)

**目的**: 快速剔除技术性废片，如模糊、过曝、无法修复的坏图。

**适用场景**: 批量导入后的第一轮筛选，快速过滤低质量图片。

```json
[
  {
    "issue": "评估图像的技术清晰度和锐利度。",
    "return_type": "array",
    "options": ["极高锐度", "标准清晰", "轻微模糊", "严重失焦/动态模糊"]
  },
  {
    "issue": "检测图像是否存在 JPEG 压缩伪影、噪点或马赛克现象。",
    "return_type": "array",
    "options": ["画质纯净", "轻微噪点", "明显压缩痕迹", "严重损坏"]
  },
  {
    "issue": "图像是否包含非内容的视觉干扰（如水印、UI图标、对话气泡、分割线）？",
    "return_type": "array",
    "options": ["纯净图像", "微小水印/Logo", "大面积水印/文本覆盖", "包含UI界面元素"]
  },
  {
    "issue": "基于构图完整性和图像可用性，给出综合技术评分（不考虑美学）。",
    "return_type": "float",
    "min": 0,
    "max": 10
  }
]
```

### 场景二：人物/二次元角色精细审核

**目的**: 专门针对 AI 生成图（Stable Diffusion/Midjourney）常见的崩坏问题进行检测。

**适用场景**: 人像摄影、二次元角色图库、AI生成图质量审核。

```json

  {

  {

    "return_type": "array",
    "options": ["手部完美/不可见", "手部结构轻微怪异", "明显的手部崩坏"]
  },

    "return_type": "array",

  {
    "issue": "图像是否为标准的全身或半身肖像？",
    "return_type": "array",
    "options": ["大头照/特写", "半身像 (Upper Body)", "全身像 (Full Body)", "非常规角度"]
  }
]
```

## 在设置中配置评估问题

### 方式一：手动添加

1. 打开 **设置** → **评估设置** 页面
2. 点击 **"添加评估问题"** 按钮
3. 填写问题描述、选择返回类型
4. 如果是 `array` 类型，添加选项
5. 如果是 `float` 类型，设置最小值和最大值
6. 设置会自动保存到本地

### 方式二：批量导入（推荐）

1. 打开 **设置** → **评估设置** 页面
2. 点击 **"批量导入"** 按钮
3. 选择导入模式：
   - **逗号模式**: 适合快速输入，格式：`问题,类型,选项1,选项2,...`
   - **冒号模式**: 类似逗号模式，使用冒号分隔
   - **JSON模式**: 标准JSON格式，适合复杂配置
4. 粘贴或输入评估问题配置
5. 点击 **"导入"** 按钮
6. **注意**: 导入的问题会**追加**到现有列表，不会替换已有问题

### 批量导入格式示例

#### 逗号模式

每行一个问题，使用逗号分隔：

```text
是否为手机截图,array,是,否
图片质量评分,float,0,10
是否包含人物,array,是,否
```

**格式**: `问题,类型,选项1,选项2,...`

- 对于 `array` 类型：问题后的所有部分都是选项
- 对于 `float` 类型：问题后跟 min 和 max 值
- 对于 `text` 类型：只需问题和类型

#### 冒号模式

每行一个问题，使用冒号分隔：

```text
是否为手机截图:array:是:否
图片质量评分:float:0:10
是否包含人物:array:是:否
```

**格式**: `问题:类型:选项1:选项2:...`

- 格式与逗号模式相同，只是分隔符不同

#### JSON模式

标准JSON数组格式，最灵活：

```json
[
  {
    "issue": "是否为手机截图",
    "return_type": "array",
    "options": ["是", "否"]
  },
  {
    "issue": "图片质量评分",
    "return_type": "float",
    "min": 0,
    "max": 10
  },
  {
    "issue": "图片描述",
    "return_type": "text"
  }
]
```

**格式**: 标准JSON数组，每个对象包含完整的评估问题定义

### 编辑和管理评估问题

在评估设置页面中，每个评估问题显示为一个卡片，包含以下操作：

- **编辑问题描述**: 直接在"评估问题"输入框中修改
- **修改返回类型**: 使用下拉菜单选择类型（选项/数值/文本）
- **管理选项**（仅 `array` 类型）:
  - 在网格布局中编辑每个选项
  - 点击选项右侧的 **X** 按钮删除选项
  - 点击 **"添加选项"** 按钮添加新选项
- **设置数值范围**（仅 `float` 类型）:
  - 在"最小值"和"最大值"输入框中设置范围
- **删除问题**: 点击问题卡片底部的 **"删除此问题"** 按钮

### 界面布局说明

- **对称内联表单**: 问题输入和类型选择并排显示，自适应布局
- **响应式网格**: 选项使用响应式网格布局（小屏幕1列，大屏幕2列）
- **自动保存**: 所有修改自动保存到本地存储，无需手动保存按钮

## 使用建议

### 1. 分阶段筛选策略

**不要一次性跑所有问题**。建议采用分阶段筛选策略：

1. **第一轮：硬性质量清洗**（场景一）

   - 快速过滤模糊、损坏、水印严重的图片
   - 如果技术评分 < 3.0，直接标记为"待删除"，无需进行后续分析
   - 节省 API 成本和处理时间
2. **第二轮：内容审核**（场景二、场景五）

   - 针对人像图片进行崩坏检测
   - 进行安全分级，过滤敏感内容
3. **第三轮：分类归档**（场景三、场景四）

   - 对通过前两轮的图片进行风格分类
   - 为训练集准备素材

### 2. Float 阈值设定

对于 `float` 类型的评分，建议在代码中设定动态阈值：

- **训练集筛选**: 要求美学评分 > 8.0，技术评分 > 7.0
- **灵感库收集**: 要求美学评分 > 5.0，技术评分 > 4.0
- **快速预览**: 要求美学评分 > 3.0，技术评分 > 2.0

### 3. Prompt 优化建议

- **多模态大模型**（GPT-4V, Claude 3, LLaVA）: 使用自然语言提问效果最好，上述案例已针对此类模型优化
- **CLIP 模型**: 关键词匹配可能更有效，建议简化问题描述
- **消除歧义**: 问题描述要明确具体，避免模糊词汇（如"质量"应拆分为"技术清晰度"和"美学评分"）

### 4. 批量导入技巧

- **追加模式**: 批量导入会将新问题追加到现有列表末尾，**不会替换已有问题**
- **组合使用**: 可以先导入基础质量筛选问题，再追加其他场景的问题
- **测试验证**: 建议先用少量图片测试，确认 AI 返回结果符合预期后再批量使用
- **格式选择**:
  - JSON模式最灵活，适合复杂配置和从文档复制
  - 逗号/冒号模式适合快速输入简单问题
- **重复检查**: 导入前建议检查是否已有类似问题，避免重复

### 5. CLIP模式限制

- **重要**: 当在"分析设置"中选择"CLIP"作为审美评估方式时，评估设置页面将**不显示**
- **原因**: CLIP模型不支持自定义评估问题，只能进行基础的审美评分
- **解决方案**: 如需使用自定义评估问题，请将审美评估方式改为"AI模型"或"不使用"

## AI返回格式

AI必须严格按照以下JSON格式返回评估结果：

```json
{
  "评估图像的技术清晰度和锐利度。": "极高锐度",
  "检测图像是否存在 JPEG 压缩伪影、噪点或马赛克现象。": "画质纯净",
  "基于构图完整性和图像可用性，给出综合技术评分（不考虑美学）。": "8.5"
}
```

### 返回规范

- **array类型**: 返回值必须是 `options` 数组中的值之一
- **float类型**: 返回值必须是 min 到 max 之间的浮点数（字符串格式）
- **text类型**: 返回值可以是任意文本（建议简短）

## 解析后的结果格式

解析后的结果统一为数组格式，便于存储和查询：

```json
[
  {
    "issue": "评估图像的技术清晰度和锐利度。",
    "result": "极高锐度"
  },
  {
    "issue": "基于构图完整性和图像可用性，给出综合技术评分（不考虑美学）。",
    "result": "8.5"
  }
]
```
