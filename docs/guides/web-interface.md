# Web界面使用指南

## 快速开始

### 1. 启动Web界面

```bash
python scripts/run_web.py
```

### 2. 访问界面

在浏览器中打开：http://localhost:5000

## 功能说明

### 📋 图像列表页面

**功能**：
- 查看所有已分析的图像
- 搜索图像（按文件名或路径）
- 按标签筛选（高质量/中等质量/低质量/极低质量）
- 按评级筛选（1-5星）
- 分页浏览
- 图像预览（直接使用原图，支持懒加载）

**使用**：
1. 在搜索框输入关键词，按回车搜索
2. 选择标签或评级，点击"筛选"按钮
3. 点击图像卡片查看详情
4. 使用分页控件浏览更多图像

### 🔍 图像详情页面

**功能**：
- 查看完整图像
- 查看质量评估结果
- 查看AI分析结果
- 查看自定义评估结果
- 查看元数据信息

**使用**：
1. 在图像列表中点击图像卡片
2. 查看详细信息
3. 可以执行删除、恢复等操作

### 📊 统计信息页面

**功能**：
- 查看整体质量统计
- 查看标签分布
- 查看评级分布
- 查看质量分数分布

**使用**：
1. 点击侧边栏"统计信息"
2. 查看各种统计图表
3. 了解图像质量分布情况

### 🔄 重复检测页面

**功能**：
- 查找重复图像（基于文件哈希）
- 显示重复图像组
- 查看重复图像详情

**使用**：
1. 点击侧边栏"重复检测"
2. 查看重复图像列表
3. 选择要删除的重复图像

### 🗑️ 回收站页面

**功能**：
- 查看已删除的图像
- 恢复图像
- 永久删除图像

**使用**：
1. 点击侧边栏"回收站"
2. 查看已删除的图像列表
3. 选择恢复或永久删除

## 设置说明

### 基础设置

- **自动分析新图像**: 上传新图像时自动进行质量分析
- **审美评估方式**: 
  - 不使用审美评分
  - 基于CLIP模型评估审美
  - 基于所选AI模型评估审美
- **每页显示数量**: 图像列表每页显示的图片数量

### 分析设置

- **并发分析数量**: 同时分析的图片数量（建议3-5张）

### AI模型设置

- **AI模型**: 选择用于图像AI分析的模型
- **Ollama API地址**: 本地Ollama服务的API地址
- **Ollama模型**: 选择要使用的Ollama模型
- **API Key**: 用于访问云端AI服务的密钥

### 自定义评估

- **评估问题**: 设置AI分析时的额外评估问题
- **答案格式**: 选择AI回答问题的格式类型

### 图片源目录

- **目录列表**: 管理用于批量导入图片的源目录列表
- **自动导入**: 系统会在启动和保存设置时自动从这些目录导入图片

## 操作指南

### 分析图像

1. **选择图像**: 在图像列表中勾选要分析的图像
2. **点击分析**: 点击"分析选中图片"按钮
3. **等待完成**: 查看进度条和悬浮按钮了解进度
4. **查看结果**: 分析完成后自动刷新列表

### 删除图像

1. **选择图像**: 勾选要删除的图像
2. **点击删除**: 点击"删除选中"按钮
3. **确认删除**: 图像将移动到回收站

### 恢复图像

1. **进入回收站**: 点击侧边栏"回收站"
2. **选择图像**: 勾选要恢复的图像
3. **点击恢复**: 点击"恢复选中"按钮

### 批量导入

1. **配置目录**: 在设置中添加图片源目录
2. **自动导入**: 系统会自动导入（或点击"批量导入"）
3. **查看结果**: 在图像列表中查看导入的图片

## 快捷键

- `Ctrl + F`: 聚焦搜索框
- `Esc`: 关闭模态框
- `Enter`: 执行搜索

## 常见问题

### Q: 图片无法显示？

**A:** 
- 检查图片源文件是否存在
- 点击"清理脏数据"按钮清理无效记录
- 检查图片文件是否可正常访问

### Q: 分析很慢？

**A:**
- 减少并发分析数量
- 关闭审美评分功能
- 使用本地Ollama而不是云端模型

### Q: 设置无法保存？

**A:**
- 检查浏览器localStorage是否可用
- 清除浏览器缓存后重试
- 检查浏览器控制台是否有错误

### Q: AI分析失败？

**A:**
- 检查API密钥是否正确
- 检查网络连接
- 检查Ollama服务是否运行（如果使用Ollama）
- 查看日志文件了解详细错误

## 性能优化建议

1. **减少并发数**: 如果系统资源有限，减少并发分析数量
2. **关闭审美评分**: 如果不需要，关闭审美评分可以大幅提升速度
3. **使用本地模型**: 使用Ollama本地模型可以避免网络延迟
4. **定期清理**: 定期清理脏数据和已删除的图像
