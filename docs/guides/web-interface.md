## 快速开始

### 1. 启动后端与前端

```bash
# 终端1：启动后端 API
python scripts/run_web.py

# 终端2：启动前端应用
cd app && npm install && npm run dev
```

### 2. 访问界面

在浏览器中打开：**http://localhost:5173**

## 页面功能

### 📋 图像列表页面（首页）

**路由**: `/`

**功能**：
- 查看所有已分析的图像
- 搜索图像（按文件名或路径）
- 高级搜索（多条件组合）
- 按标签筛选（高质量/中等质量/低质量/极低质量）
- 按评级筛选（1-5星）
- 按质量分数范围筛选
- 分页浏览
- 图像预览（直接使用原图，支持懒加载）
- 列表/宫格视图切换
- 批量选择和管理

**使用**：
1. 在搜索框输入关键词，按回车搜索
2. 点击"高级搜索"展开更多筛选条件
3. 选择标签或评级，点击"筛选"按钮
4. 点击图像卡片查看详情
5. 使用分页控件浏览更多图像
6. 点击视图切换按钮切换列表/宫格视图

### 🔍 图像详情页面

**路由**: `/image/<image_id>`

**功能**：
- 查看完整图像（原图）
- 查看质量评估结果（模糊度、亮度、信息熵、BRISQUE等）
- 查看AI分析结果（图像描述、质量评估）
- 查看自定义评估结果
- 查看XMP元数据信息
- 查看完整元数据（EXIF、GPS、XMP、IPTC等，点击"加载完整元数据"按钮）
- 删除图像（移动到回收站）

**使用**：
1. 在图像列表中点击图像卡片
2. 查看详细信息
3. 点击"加载完整元数据"按钮查看所有元数据（EXIF、GPS、XMP等）
4. 可以执行删除、AI分析等操作

**完整元数据功能**：
- 点击"加载完整元数据"按钮，系统会读取图像文件的所有元数据
- 元数据按类别组织显示（基本信息、相机信息、GPS信息、XMP信息等）
- 如果ExifTool不可用，会显示数据库中的元数据并提示安装ExifTool

### 📊 统计信息页面

**路由**: `/stats`

**功能**：
- 查看整体质量统计
- 查看标签分布（饼图）
- 查看评级分布（柱状图）
- 查看质量分数分布（直方图）
- 查看图像总数和已分析数量

**使用**：
1. 点击侧边栏"统计信息"
2. 查看各种统计图表
3. 了解图像质量分布情况

### 🔄 重复检测页面

**路由**: `/duplicates`

**功能**：
- 查找重复图像（基于文件MD5哈希）
- 显示重复图像组
- 查看重复图像详情
- 识别完全相同的图像文件

**使用**：
1. 点击侧边栏"重复检测"
2. 查看重复图像列表
3. 每个重复组显示所有重复图像的路径和大小
4. 可以点击查看详情，决定保留哪个

### 🗑️ 回收站页面

**路由**: `/trash`

**功能**：
- 查看已删除的图像（显示删除时间）
- 恢复图像（移回原位置）
- 永久删除图像（真正删除文件和数据库记录）
- 批量操作（批量恢复、批量永久删除）
- 选择模式（支持多选操作）

**使用**：
1. **进入回收站**: 点击侧边栏"回收站"
2. **查看已删除图像**: 浏览已删除的图像列表，查看删除时间
3. **恢复图像**: 
   - 点击单个图像的"恢复"按钮，或
   - 选择多个图像后点击"批量恢复"按钮
   - 图像将自动移回原始位置
4. **永久删除图像**: 
   - 点击单个图像的"永久删除"按钮
   - 系统会显示确认对话框（红色警告样式）
   - 确认后图像文件和数据库记录将被永久删除
   - 支持批量永久删除（选择多个图像后点击"永久删除"按钮）
5. **批量操作**: 
   - 使用复选框选择多个图像
   - 点击顶部工具栏的"批量恢复"或"永久删除"按钮
   - 批量永久删除会显示确认对话框，显示要删除的图像数量

**注意事项**：
- ⚠️ **永久删除不可恢复**: 永久删除操作不可撤销，请谨慎操作
- ✅ **恢复功能**: 软删除的图像可以随时恢复
- 📁 **路径保留**: 恢复时会保留原始路径结构
- 🔄 **冲突处理**: 如果原位置已有同名文件，会自动重命名

### ⚙️ 系统信息页面

**路由**: `/system`

**功能**：
- 查看Python版本和系统信息
- 检查依赖是否安装
- 检查AI模型状态
- 查看数据库信息

**使用**：
1. 点击侧边栏"系统信息"
2. 查看系统环境信息
3. 检查依赖和模型状态

## 操作指南

### 分析图像

#### 方式1: 自动分析（推荐）

1. 在设置中启用"自动分析新图像"
2. 导入图片时自动进行分析

#### 方式2: 手动分析

1. **选择图像**: 在图像列表中勾选要分析的图像
2. **点击分析**: 点击"分析选中图片"按钮
3. **等待完成**: 查看进度条和悬浮按钮了解进度
4. **查看结果**: 分析完成后自动刷新列表

#### 方式3: 批量分析所有

1. 点击"分析所有图片"按钮
2. 系统会分析所有未分析的图像
3. 查看进度和结果

### 删除图像

#### 单个删除

1. 在图像列表中点击图像卡片的"删除"按钮
2. 系统会显示确认对话框（黄色警告样式）
3. 确认后图像将移动到回收站（软删除）

#### 批量删除

1. **进入选择模式**: 点击"选择模式"按钮
2. **选择图像**: 勾选要删除的图像
3. **批量删除**: 点击"删除选中"按钮
4. **确认删除**: 图像将移动到回收站

### 恢复图像

1. **进入回收站**: 点击侧边栏"回收站"
2. **选择图像**: 勾选要恢复的图像（或直接点击单个图像的"恢复"按钮）
3. **点击恢复**: 点击"恢复"或"批量恢复"按钮
4. **自动恢复**: 图像将自动移回原位置，如果原位置已有同名文件会自动重命名

### 批量导入

#### 方式1: 自动导入（推荐）

1. **配置目录**: 在设置中添加图片源目录
2. **自动导入**: 系统会在启动和保存设置时自动导入
3. **查看结果**: 在图像列表中查看导入的图片

#### 方式2: 手动导入

1. 点击"批量导入"按钮
2. 系统会从配置的目录导入图片
3. 查看导入结果

### 清理评估数据

1. **选择图像**: 勾选要清理评估数据的图像
2. **点击清理**: 点击"清理评估"按钮
3. **选择类型**: 选择要清理的类型（质量评估/自定义评估）
4. **确认清理**: 评估数据将被清除

### 搜索和筛选

#### 普通搜索

1. 在搜索框输入关键词
2. 按回车或点击搜索按钮
3. 系统会搜索文件名和路径

#### 高级搜索

1. 点击"高级搜索"按钮展开搜索面板
2. 设置多个搜索条件：
   - 文件名/路径关键词
   - 评级范围
   - 标签
   - 质量分数范围
3. 点击"搜索"按钮执行搜索
4. 点击"重置"清除搜索条件

## 设置说明

### 基础设置

- **自动分析新图像**: 上传新图像时自动进行质量分析
- **每页显示数量**: 图像列表每页显示的图片数量（10/20/50/100）

### 分析设置（包含AI配置）

#### 分析配置
- **审美评估方式**: 
  - 不使用审美评分
  - 基于CLIP模型评估审美（需要安装transformers和torch）
  - 基于所选AI模型评估审美（需要配置AI模型）
- **写入XMP元数据**: 分析时自动将结果写入图像的XMP元数据

#### AI配置
- **启用AI分析**: 是否启用AI分析功能
- **AI模型**: 选择用于图像AI分析的模型
  - Ollama (本地) - 推荐，无需API密钥
  - GPT-4 Vision (OpenAI)
  - Claude 3 (Anthropic)
  - Gemini Pro Vision (Google)
- **Ollama配置**（仅当选择Ollama时显示）:
  - **Ollama API地址**: 本地Ollama服务的API地址（默认：http://localhost:11434）
  - **Ollama模型**: 选择要使用的Ollama模型（如：llava, qwen2-vl）
- **API Key**（仅当选择云端模型时显示）: 用于访问云端AI服务的密钥（GPT-4V、Claude、Gemini需要）

### 自定义评估

- **评估问题**: 设置AI分析时的额外评估问题
  - 问题格式：JSON数组
  - 支持的问题类型：array（选择）、float（评分）、text（文本）
- **答案格式**: 选择AI回答问题的格式类型

详细格式说明请查看 [评估格式说明](./evaluation-format.md)

### 数据管理

#### 图片源目录

- **目录列表**: 管理用于批量导入图片的源目录列表
- **添加目录**: 点击"添加目录"按钮，输入目录路径
- **验证目录**: 系统会自动验证目录是否存在
- **重新索引**: 点击"重新索引图片"按钮，根据当前目录列表扫描并更新数据库中的图片记录

#### XMP元数据写入

- **自动写入XMP元数据**: 分析图像时自动将质量评分、评级、标签、关键词等信息写入图像的XMP元数据
  - **默认启用**: 系统默认会写入XMP元数据
  - **兼容性**: 使用标准XMP标签，兼容Adobe Lightroom、Capture One、Luminar、ON1 Photo RAW等主流图像管理软件
  - **关键词生成**: 
    - 自动从质量分析中生成关键词（质量标签、问题检测等）
    - 如果启用AI分析，会自动从AI分析文本中提取关键词
    - 关键词会合并去重后追加到XMP（保留原有关键词）
  
  - **元数据保护** ⚠️ **重要**:
    - ✅ **绝对不覆盖**：个人信息、时间、地点、摄影参数等原有元数据
    - ✅ **仅追加写入**：使用追加模式，保留所有原有信息
    - ✅ **安全可靠**：使用ExifTool的`-preserve`选项保护所有现有元数据
    - ✅ **字段白名单**：仅写入质量分析相关字段，不触及敏感元数据
  
  - **ExifTool安装**（自动下载）:
    - **系统会在首次启动时自动下载ExifTool，无需手动操作！**
    - 启动项目时自动检测，如果未找到会自动下载到 `exiftool/` 目录
    - 完全自动化，用户无需任何操作
    - **手动安装（可选）**: 如果自动下载失败
      - Windows: 从 https://exiftool.org/ 下载并添加到PATH
      - macOS: `brew install exiftool`
      - Ubuntu: `sudo apt-get install libimage-exiftool-perl`

## 常见问题

### Q: 图片无法显示？

**A:** 
- 检查图片源文件是否存在
- 点击"清理脏数据"按钮清理无效记录
- 检查图片文件是否可正常访问
- 查看浏览器控制台是否有错误

### Q: 分析很慢？

**A:**
- 后端并发分析数量由后端配置控制（默认1）
- 关闭审美评分功能
- 使用本地Ollama而不是云端模型
- 检查系统资源使用情况

### Q: 设置无法保存？

**A:**
- 检查浏览器localStorage是否可用
- 清除浏览器缓存后重试
- 检查浏览器控制台是否有错误
- 尝试使用其他浏览器

### Q: AI分析失败？

**A:**
- 检查API密钥是否正确（云端模型）
- 检查网络连接
- 检查Ollama服务是否运行（如果使用Ollama）
- 查看日志文件了解详细错误：`logs/image_quality.log`
- 检查模型是否已下载（Ollama）

### Q: 导入的图片没有显示？

**A:**
- 检查目录路径是否正确
- 检查目录中是否有支持的图片格式
- 点击"批量导入"手动导入
- 查看日志文件了解导入详情

### Q: 如何清理脏数据？

**A:**
- 点击"清理脏数据"按钮
- 系统会自动删除源文件不存在的记录
- 清理后刷新列表查看结果

## 性能优化建议

1. **后端并发控制**: 后端默认并发数为1，可根据系统资源调整后端配置
2. **关闭审美评分**: 如果不需要，关闭审美评分可以大幅提升速度
3. **使用本地模型**: 使用Ollama本地模型可以避免网络延迟
4. **定期清理**: 定期清理脏数据和已删除的图像
5. **使用懒加载**: 图片使用懒加载，提高页面加载速度（已默认启用）

## 前端架构

Web界面采用现代化的 React + TypeScript 架构，实现高内聚、低耦合：

- **React组件化**: 功能按组件划分，职责单一
- **状态管理**: 使用Zustand进行轻量级状态管理
- **数据获取**: 使用React Query管理服务器状态和缓存
- **实时通信**: WebSocket实现分析进度实时更新
- **类型安全**: 完整的TypeScript类型定义

详细架构说明请查看 [架构文档](../architecture/README.md#前端架构)
