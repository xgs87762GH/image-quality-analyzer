# Image Quality Analyzer - Frontend

React + TypeScript + Vite 前端应用

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

## 技术栈

- React 18 + TypeScript
- Vite 5
- React Router 6
- Zustand (状态管理)
- TanStack Query (数据获取)
- Socket.io Client (WebSocket)
- react-i18next (国际化)
- shadcn/ui (UI 组件)
- Tailwind CSS

## 项目结构

```
src/
├── components/    # 组件
├── pages/        # 页面
├── hooks/        # 自定义 Hooks
├── services/     # 服务层（API、WebSocket）
├── stores/       # 状态管理
├── types/        # TypeScript 类型
├── utils/        # 工具函数
├── locales/      # 多语言资源
├── i18n/         # i18n 配置
└── styles/       # 样式文件
```
